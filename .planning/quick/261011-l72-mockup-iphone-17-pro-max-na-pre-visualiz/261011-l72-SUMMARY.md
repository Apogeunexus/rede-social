# Phase quick-261011-l72 Plan 01: iPhone 17 Pro Max mockup in the panels preview Summary

From 1024 px up, every `/painel-preview/<nivel>` level now renders its panel inside a server-rendered iPhone 17 Pro Max frame. The screen is 440x956 with a 55 px radius, a dark bezel, a Dynamic Island, a "9:41" status bar from the catalog with lucide Signal/Wifi/BatteryFull icons and a home indicator. The screen scrolls on its own and the frame scales to the window height. The panels lay out against an `@3xl` container query, so they show their phone layout inside the frame and their wide layout unframed. The explanatory notes are gone; a single "Dados de exemplo" tag keeps `PREVIEW_NOTE_ID`.

## What was built

- **PhoneMockup** (`apps/web/components/dashboard/PhoneMockup.tsx`): an async server component.
  - Reserved box `[data-phone-frame]` with `--phone-scale: min(1, tan(atan2(100dvh - 4rem, 980px)))`.
  - The bezel is scaled with a transform.
  - Screen `[data-phone-screen]`: 440x956, `overflow-y: auto`, hidden scrollbar, `overscroll-contain`, flex column.
  - A sticky status bar holds the Dynamic Island.
  - The panel wrapper carries `@container`.
  - The home indicator is sticky at the bottom.
  - Every frame class is `lg:` only, so below 1024 px the panel is a plain block.
- **Page**: from lg up, two columns, with PreviewChrome on the left (`lg:max-w-sm`) and the phone on the right. Below lg the order is the same as before: chrome first, then the panel.
- **D-01 notes removed**:
  - Removed from the page: the intro, the "Todos os números…" paragraph and the context card.
  - Removed from the catalog: `preview.intro`, `preview.noticeBody`, `chrome.role|question|missing`, `availability`, and `levels.*.question|usage|missing`.
  - Removed from `dashboard-preview.ts`: the `PreviewRole` and `PreviewAvailability` types and the `role` and `availability` fields.
  - Added `preview.noticeDescription`. It is the sr-only accessible text of the single tag, so every disabled action's description reads "Dados de exemplo: números, nomes e clientes são fictícios e as ações estão desativadas."
  - The production gate (`await connection()` + `notFound()`) is unchanged.
- **D-04 container queries**: there are 7 `@3xl:` variants.
  - ResponsiveTable ×2
  - TenantColumn
  - PlatformAdminPanel
  - PlatformOwnerPanel
  - TenantOwnerPanel ×2

  No viewport breakpoint is left under `apps/web/components/dashboard` (PhoneMockup's window-level `lg:` excepted) or `packages/modules/dashboard/ui`.
- **Planner choice (named, as required): `@3xl` vs `@md`.** Tailwind 4.3.3 `--container-md` is 28rem, while `--container-3xl` is 48rem, the old `--breakpoint-md`. With `@3xl` the threshold stays the same width. The only change below lg: unframed, the container is the page content box (window − 2rem), so the switch moves from a **768 px window to an 800 px window**.
